# PCG Attribute Reference

This document lists the canonical metadata attributes generated by the UE 5.6 PCG migration. Attribute scopes align with the helper builders in `PCGWorldService` and are validated by `ValidateInputAttributes`.

## Parameter Metadata (`UPCGParamData`)

| Attribute | Type | Required | Description |
|-----------|------|----------|-------------|
| `AverageHeight` | float | Yes | Mean world-space height across the tile samples. |
| `MinHeight` | float | Yes | Minimum world-space height within the tile. |
| `MaxHeight` | float | Yes | Maximum world-space height within the tile. |
| `AverageSlope` | float | Yes | Average slope magnitude (degrees). |
| `MaxSlope` | float | Yes | Highest slope magnitude (degrees). |
| `WaterCoverage` | float | Yes | Ratio [0..1] representing the percentage of samples below sea level. |
| `AverageAboveWater` | float | Yes | Mean height delta for samples above sea level. |
| `AverageBelowWater` | float | Yes | Mean depth for samples below sea level. |
| `MinWaterDistance` | float | Yes | Smallest distance to water for any sample (centimetres). |
| `SeaLevel` | float | Yes | World-space sea level used for metrics. |
| `TileSize` | float | Yes | Tile width/length in world units. |
| `BiomeWeight` | float | Yes | Designer weight applied to biome blending (1.0f default). |
| `BiomeId` | int32 | Yes | Enum value of the biome used for the tile. |
| `TileX` | int32 | Yes | Tile coordinate (X). |
| `TileY` | int32 | Yes | Tile coordinate (Y). |
| `TileSeed` | int32 | Yes | Deterministic seed generated from `Hash(TileX, TileY, BiomeId, WorldGenSettings.Seed)`. |

## Point Metadata (`UPCGPointData`)

| Attribute | Type | Required | Description |
|-----------|------|----------|-------------|
| `AverageSlope` | float | No | Copy of parameter-average slope for convenience when points require it. |
| `StaticMesh` | `FSoftObjectPath` or `UStaticMesh*` | No | Preferred mesh reference for the instance. Designers should use soft references. |
| `Mesh` | `FSoftObjectPath` | No | Legacy alias used by some graphs. Only read when `StaticMesh` is missing. |
| `InstanceScale` | `FVector` | No | Overrides the transform scale for the instance. Defaults to point transform scale. |
| `InstanceRotation` | `FRotator` | No | Overrides the rotation for the instance. Defaults to point transform rotation. |
| `IsActive` | bool | No | Allows graphs to disable spawning for a point (defaults to true). |
| `InstanceId` | `FGuid` or string GUID | No | Stable identifier for deduping/persistence. A new GUID is generated if missing/invalid. |

### Tile Seed Notes

`TileSeed` is mixed using the hash combination sequence: `HashCombine(HashCombine(HashCombine(Hash(TileX), Hash(TileY)), Hash(BiomeId)), Hash(WorldSeed))`. The resulting value is clamped to 31 bits and stored as `int32` so that scheduler, random streams, and metadata consumers share a stable deterministic seed.

## Scope Audit

- **Parameter metadata** is produced by `PCGWorldService::Private::CreateTileParameterData` and consumed by `ValidateInputAttributes` before graph scheduling.
- **Point metadata** is produced by `PCGWorldService::Private::CreateTilePointData` and consumed by `ExtractInstancesFromPointData` and the validation helper.
- `ValidateInputAttributes` enforces the scopes listed above and logs type mismatches or missing fields. Unknown attributes remain untouched but generate warnings to help authors align graphs with the canonical contract.

## Usage Guidance

- Designers should prefer soft references for `StaticMesh` so cooked builds do not hard-load assets.
- Optional attributes can be omitted; runtime will fall back to default transform/behaviour and issue a warning once per attribute name.
- Keep attribute names stable; the validation helper and CI checks flag any deviations.
